# Financial-AI-Agent
This is a local AI agent that analyzes personal finance CSV files and generates insights using a local Mistral-7B model. Upload your transaction CSVs, run the script, and get a breakdown of spending by category plus AI-generated recommendations. No data leaves your machine.

Requirements before running:
Download the Mistral-7B model from Hugging Face:
https://huggingface.co/TheBloke/Mistral-7B-Instruct-v0.2-GGUF
Download the file named mistral-7b-instruct-v0.2.Q4_K_M.gguf and save it anywhere on your computer.
Then open the script and update the model_path line to point to where you saved it.
